# 程序员简约个人博客 - 产品需求文档

## 1. 产品概述

一个纯静态的程序员个人博客网站，所有内容集成在单个 HTML 文件中，无需服务器、数据库或外部依赖。目标用户是程序员和技术爱好者，追求极简、代码感强的视觉风格，类似 GitHub Pages 的设计语言。

## 2. 核心功能

### 2.1 页面结构
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 首页 | 导航栏 | 顶部固定导航，含博客标题和三个链接 |
| 首页 | 个人信息区 | 博客标题 + 简短个人介绍 |
| 首页 | 最新文章列表 | 显示标题、发布日期、简短摘要 |
| 文章列表页 | 文章列表 | 所有文章按时间倒序排列 |
| 文章详情页 | 文章内容 | Markdown 风格排版，代码块深色高亮 |
| 关于我页 | 个人介绍 | 简单介绍 + 技术栈标签展示 |

### 2.2 导航栏要求
- 桌面端：水平排列，固定在顶部
- 移动端：可折叠汉堡菜单，适配竖屏

## 3. 设计风格

### 3.1 视觉规范
- **配色方案**：极简黑白灰
  - 主色：#000000（纯黑）
  - 背景色：#FFFFFF（纯白）
  - 辅助色：#333333（深灰）、#666666（中灰）、#999999（浅灰）
  - 强调色：#00ff00（终端绿色，用于代码块）
- **字体**：无衬线字体栈（-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif）
- **布局**：简洁留白，无多余装饰
- **代码块样式**：深色背景（#1e1e1e）、绿色文字、圆角边框

### 3.2 响应式设计
- 移动端优先适配
- 断点：768px（平板/桌面）
- 移动端导航栏可折叠

## 4. 文章系统

### 4.1 第一篇文章（使用教程）
- **标题**：如何在这个静态博客里发布第一篇文章
- **发布日期**：2026-05-12
- **摘要**：这是一份手把手教程，教你如何修改 HTML 文件，在这个博客里添加、编辑和发布新文章。

### 4.2 文章内容结构
1. 博客简介
2. 准备工作
3. 第一步：复制文章模板
4. 第二步：修改文章信息
5. 第三步：添加文章内容
6. 第四步：保存并查看
7. 进阶玩法（可选）
8. 结尾鼓励语

### 4.3 代码示例要求
- 使用 `<pre><code>` 标签包裹
- 深色背景 #1e1e1e
- 绿色文字 #00ff00
- 终端风格展示

## 5. 技术实现

### 5.1 单文件架构
- 所有 HTML、CSS、JavaScript 写在一个 index.html 文件中
- 无外部依赖，可直接在浏览器打开运行

### 5.2 页面路由
- 使用 JavaScript 实现单页应用（SPA）路由
- 三个视图：首页、文章列表、文章详情、关于我
- 通过 hash 路由（#/、#/articles、#/article/1、#/about）切换

## 6. 用户交互

### 6.1 导航交互
- 点击导航链接平滑切换视图
- 当前页面高亮显示
- 移动端汉堡菜单点击展开/收起

### 6.2 文章交互
- 点击文章标题或卡片跳转详情页
- 返回按钮回到文章列表

## 7. 性能要求

- 首屏加载时间 < 1秒
- 单文件大小 < 50KB
- 纯静态，无需网络请求
