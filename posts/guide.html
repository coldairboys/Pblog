本博客使用教程

手把手教你发布新博客文章 | 最后更新：2026-05-12

欢迎使用 CodeLog！这是一个纯静态博客，无需服务器、数据库，所有文件都在本地，修改即可更新。本教程将详细讲解如何在这个博客上添加和管理你的文章。

一、博客目录结构

这是一个标准的多文件静态博客结构：

blog/ ├── index.html ← 首页 ├── css/ │ └── style.css ← 全局样式 ├── js/ │ └── main.js ← 交互逻辑 └── posts/ └── guide.html ← 教程文章

每个文件的作用：

  • index.html - 网站首页，展示博客入口
  • css/style.css - 控制所有页面的样式
  • js/main.js - 控制导航栏等交互功能
  • posts/*.html - 你的文章页面，放在 posts 文件夹

二、新增文章步骤

第一步
创建文章文件

在 posts/ 文件夹中创建一个新的 HTML 文件，文件名建议使用英文，如 my-first-post.html。

第二步
复制模板

复制下面的文章模板到你的新文件中：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>你的文章标题</title>
    <link rel="stylesheet" href="../css/style.css">
</head>
<body>
    <header class="header">
        <nav class="nav">
            <div class="nav-brand">
                <a href="../index.html"><CodeLog/></a>
            </div>
            <button class="nav-toggle" id="navToggle" aria-label="菜单">
                <span></span>
                <span></span>
                <span></span>
            </button>
            <ul class="nav-menu" id="navMenu">
                <li><a href="../index.html">首页</a></li>
                <li><a href="guide.html">教程</a></li>
            </ul>
        </nav>
    </header>

    <main class="main">
        <article class="post-content">
            <!-- 在这里写你的文章内容 -->
        </article>
    </main>

    <script src="../js/main.js"></script>
</body>
</html>
第三步
修改文章内容

在 <main> 标签内编写你的文章。使用以下格式：

<h1>文章大标题</h1>
<p>段落文字...</p>
<h2>二级标题</h2>
<ul>
    <li>列表项 1</li>
    <li>列表项 2</li>
</ul>
<pre><code>代码块内容</code></pre>
第四步
添加文章链接

打开 index.html，在文章列表中添加你的文章链接：

<a href="posts/my-first-post.html" class="article-card">
    <span class="article-date">2026-05-13</span>
    <h3 class="article-title">我的第一篇文章</h3>
    <p class="article-summary">文章摘要...</p>
    <span class="read-more">阅读全文 →</span>
</a>

三、修改内容方法

修改博客名称

打开 index.html，找到 <h1>CodeLog</h1> 和 <p class="subtitle">...</p>，修改为你的内容。

修改个人简介

在 index.html 中找到 <p class="intro">...</p>，修改里面的文字。

修改样式

打开 css/style.css，修改顶部的 CSS 变量：

:root {
    --bg: #ffffff;
    --text: #1a1a1a;
    --text-secondary: #666666;
    --border: #e5e5e5;
    --code-bg: #1e1e1e;
    --code-text: #00ff00;
    --link: #0066cc;
    --link-hover: #0052a3;
}

添加代码块

使用 <pre><code> 标签包裹代码，会自动显示为深色终端风格：

<pre><code>
const greeting = "Hello World";
console.log(greeting);
</code></pre>

添加提示框

使用 .tip 类添加提示框：

<div class="tip">
    💡 提示：记得保存文件后再刷新浏览器！
</div>

四、手机查看方式

方法一：本地预览

将博客文件夹通过微信、QQ、AirDrop 等方式传到手机，然后用手机浏览器打开 index.html 文件即可。

方法二：局域网预览

在电脑上启动一个简单的 HTTP 服务器（需要 Python）：

# Windows
python -m http.server 8080

# Mac/Linux
python3 -m http.server 8080

然后确保手机和电脑在同一 WiFi 网络下，用手机浏览器访问 电脑IP地址:8080。

💡 查找电脑 IP 地址：
Windows: 打开CMD，输入 ipconfig
Mac: 打开终端，输入 ifconfig | grep inet

方法三：部署到 GitHub Pages

  1. 在 GitHub 创建一个新仓库
  2. 把博客所有文件上传到仓库
  3. 进入仓库 Settings → Pages
  4. Source 选择 main 分支
  5. 等待部署完成，访问 你的用户名.github.io/仓库名

五、常用 HTML 标签速查

<h1> ~ <h6>    标题（h1最大，h6最小）
<p>            段落
<ul> / <li>    无序列表
<ol> / <li>    有序列表
<strong>       粗体
<em>           斜体
<code>         行内代码
<pre><code>     代码块
<a href="">    链接
<div>          区块容器
<span>         行内容器

六、文件路径说明

所有路径都使用相对路径，确保本地可以直接打开：

  • 从 posts/ 引用 css/: ../css/style.css
  • 从 posts/ 引用 js/: ../js/main.js
  • 从 posts/ 链接到首页: ../index.html
⚠️ 注意：一定要使用 ../ 返回上级目录，因为 posts/ 比 css/ 低一级。
